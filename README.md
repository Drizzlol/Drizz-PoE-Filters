
# TTS FILTER MODULE AVAILABLE

Base filter shows all armor types and weapons.

Filter reskin.

TTS for specific item drops.

# How To Use

**STEP 1:**

- Download the sounds folder.

<img width="1453" height="446" alt="chrome_yGftq7zxEZ" src="https://github.com/user-attachments/assets/456b1bb1-8e30-409d-839e-79c07df46bba" />

- Put the sound files (from either the english or japanese folders)
 in your filter folder "Documents > My Games > Path of Exile 2"

 <img width="1453" height="592" alt="PathOfExileSteam_9J3y6PYiJ1" src="https://github.com/user-attachments/assets/a585077f-e96e-49e0-8453-fb85b69c9bdb" />

**STEP 2:**

- Open your filter (or create a new one).
- Click Modules
- Select Public tab
- Search "drizz" in author
- Add "Drizz Comfy Filter" module
- Apply

<img width="1453" height="599" alt="chrome_hO2rHAW6Lw" src="https://github.com/user-attachments/assets/2546df03-e6c8-4034-8236-e7dd901e211d" />


**STEP 3:** ***(Optional)***

If using a base filter you may want to hide bases you're not interested in, in the filterblade settings.

Can also refine the ranks of any of my filters in the filterblade settings.
